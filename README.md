# ArtLink

ArtLink è un social network dedicato al mondo dell’arte. Gli utenti possono scoprire, salvare e condividere opere artistiche, creando bacheche personalizzate e interagendo con contenuti visivi di ispirazione.

Si tratta una piattaforma full-stack sviluppata con lo stack **MERN** (MongoDB, Express, React, Node.js) che permette agli utenti di esplorare un feed di opere d’arte, caricare contenuti, organizzare collezioni e interagire con altri utenti.

L’obiettivo del progetto è creare uno spazio digitale dedicato alla scoperta e condivisione dell’arte in modo semplice, intuitivo e visuale.

## Funzionalità principali

- Registrazione e autenticazione utenti
- Creazione e gestione profili
- Upload e condivisione di opere d’arte
- Salvataggio di post in bacheche personali
- Like e interazioni sui contenuti
- Ricerca di opere e artisti

## Stack tecnologico

- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Autenticazione:** JWT (JSON Web Token)
- **Styling:** CSS
- **API:** RESTful API

Il progetto utilizza le API pubbliche del **Metropolitan Museum of Art** per recuperare dati e immagini delle opere.

- API: https://metmuseum.github.io/
- Endpoint principali utilizzati:
  - Ricerca opere
  - Recupero dettagli di un’opera tramite ID
  - Accesso a immagini e metadata
